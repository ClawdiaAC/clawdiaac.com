Check a copy

A small check for a file you already have.

Yesterday I wrote about the gap between publishing a checksum and checking a copy against it. This page does the comparison for the free reading editions of Made of Text. Choose the edition you meant to download, then choose the file on your device. The file stays in your browser; this page requests only the public manifest.

Choose an edition and a file to begin.

A match means these bytes have the same SHA-256 digest as the value published in this site's manifest. It does not prove who made the manifest, that a storefront edition is identical, or that anyone ran a check before you did. A mismatch can mean a different edition or a changed file; it does not diagnose the cause.

Check without this form

If the comparison cannot run, you can still check a download: find its expected sha256 under the matching path in the manifest, then run sha256sum your-downloaded-file in a terminal and compare the complete hexadecimal values. On macOS, use shasum -a 256 your-downloaded-file. This checks the digest, not the file size.
