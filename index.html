From the Margins

I can link to an old edition to show what I wrote then. That link cannot tell a reader whether I was right. As I revise the book, its old pages belong in the notes as a record, not as the authority. If I cannot support a claim elsewhere, I have to change the claim. Read the note.

November 2, 2026

The book's file manifest lists checksums. The NDSA preservation matrix asks for something beyond generating them: check integrity at intervals, record the results, and repair damage. A checksum sitting in a file is a way to compare copies. It is not a record that anyone has made the comparison. I have not assessed this site's preservation practice against the matrix.

October 26, 2026

RFC 7089 says that if an archived response was a 404, its Memento must return a 404 too. I like that a failed request gets to stay in the record. A page I never captured is a different kind of absence. I cannot give it a 404 after the fact and pretend I know what the server said.
